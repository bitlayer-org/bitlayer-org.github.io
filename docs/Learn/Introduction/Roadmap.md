## **Vision**

Bitlayer is a movement to redefine what's possible with Bitcoin, spanning cross-chain interoperability, Bitcoin-equivalent security, and scalability for decentralized finance.

## Roadmap

![Roadmap](/img/Introduction/roadmap3.png)

### **First Stage: Bitlayer PoS, the Foundation**

**Mainnet-V1 | 2024**

This foundational phase combines Proof of Stake with multisignature technology and collaborates with multiple MPC custody platforms. The infrastructure maintains full EVM compatibility to onboard users and developers seamlessly.

Key milestones:
- Security model combining PoS and multisig
- Cross-chain functionality enabling asset movement between BTC, EVM-based chains, and other networks
- EVM compatibility — Solidity applications migrate effortlessly, with ultra-low gas fees
- BitVM Bridge Testnet Launch (Dec 2024)
- Mint Features — enabling BTC minting on Bitlayer

### **Second Stage: Bitlayer BitVM, Based**

**Mainnet-V2 | 2025**

The BitVM paradigm is implemented and deployed in the BTC Bridge, representing a major advancement in security assumptions. This stage validates the core cryptographic assumptions and dispute mechanisms underlying BitVM.

Key milestones:
- Trust-Minimized BTC Bridge — replaces the earlier multisig-based solution with enhanced decentralization and security
- New Functions Launch — expanded bridge capabilities
- Unmint & Reclaim Process — enabling BTC redemption and reclaim workflows
- Mainnet Beta Launch (Ethereum) — live bridge deployment on Ethereum

### **Third Stage: Bitlayer BitVM, Enhanced**

**Mainnet-V3 | 2026–**

After the foundational version proves viable between Bitcoin and Ethereum, this enhanced phase focuses on expanding functionality, strengthening security guarantees, and scaling beyond initial capabilities.

Key advancements:
- BitVM Evolves — advanced dispute mechanisms, optimized proof efficiency, reduced verification overhead, and more robust fault-tolerance for higher throughput
- More Chains — multi-chain expansion beyond Ethereum, evolving the bridge into a secure, scalable interoperability hub for Bitcoin
